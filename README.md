<h1>guita's Woodworks</h1>
<p>🪓 <b>Decorations that have some sort of chopped charm!</b> 🪓</p>
</center>

This mod adds 4 types of versatile wood blocks *(Maybe more in the future)* for all of the wood types, these blocks are the **stump** block, **carved log** block, **beam** block, the **hollow log** block and all of the respective stripped variants.

---

## Features

- **Sittable blocks:** You can sit on the stump and carved log blocks.

- **Beam block:** You can change it's size clicking it with shears or change it's connections with the new item **secateurs**.

- **Fuel:** The stumps will burn for 150 ticks, the carved logs will burn for 250 ticks, the beams will burn for 75 ticks and the hollow logs will burn for 150 ticks.

- **Modded Woods**: Fully compatible with [Every Compat (WoodGood)](https://modrinth.com/mod/every-compat) for modded wood types.
